HOW TO USE
───────────────────────────────────────────────────────────────────────────────

STEP 1: TRAIN MODEL (One-time or monthly)
════════════════════════════════════════════════════════════════════════════════

  Command:
  $ python scripts/train_churn_model.py churn_data.csv

  What happens:
  1. Loads CSV file with validation
  2. Checks required columns present
  3. Engineers 50+ features automatically
  4. Trains 5 models with 5-fold cross-validation
  5. Compares performance
  6. Tunes hyperparameters (optional, slower)
  7. Saves best model to ml/models/
  8. Generates comprehensive report

  Time: ~3-5 minutes (depends on dataset size)
  Output:
  ✓ ml/models/churn_model_20260502_120000.pkl
  ✓ ml/models/feature_importance_*.csv
  ✓ ml/models/model_report_*.txt
  ✓ ml/models/model_comparison_*.json

MODERN ML TECHNIQUES IMPLEMENTED
───────────────────────────────────────────────────────────────────────────────

✅ Stratified Cross-Validation
   Ensures each fold has similar class distribution
   Better generalization estimates

✅ Class Weight Balancing
   Handles imbalanced data (80% retained, 20% churned)
   Prevents bias toward majority class

✅ Feature Scaling (RobustScaler)
   Resistant to outliers (better for business data)
   Better than StandardScaler

✅ Hyperparameter Tuning (GridSearchCV)
   Systematic search for optimal parameters
   Better than manual guessing

✅ Feature Importance Analysis
   Understand which features drive predictions
   Actionable business insights

✅ Optimal Threshold Tuning
   Youden's J statistic for best threshold
   Better than default 0.5

✅ Ensemble Methods
   Multiple models combined for robustness
   Gradient boosting state-of-the-art

✅ Model Persistence
   Save/load trained models
   Reproducible predictions

TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Problem: "Missing required columns"
Solution: Ensure CSV has: Age, Gender, Tenure, Support Calls, Payment Delay,
          Subscription Type, Contract Length, Total Spend, Churn

Problem: "No module named 'ml'"
Solution: Make sure you're running from output/ directory with correct Python path

Problem: "Model not found" in Predictions page
Solution: Train model first: python scripts/train_churn_model.py churn_data.csv

Problem: Slow training time
Solution: Normal for large datasets. Try with smaller sample first.

Problem: Low accuracy
Solution: Check data quality, ensure churned/retained split is reasonable
