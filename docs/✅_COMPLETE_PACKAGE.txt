 📋 DATA REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Your CSV file should have these columns:

REQUIRED:
  • CustomerID      (unique identifier)
  • Age             (numeric: 18-80)
  • Tenure          (numeric: 0-80 months)
  • MonthlyCharges  (numeric: $0-150)
  • TotalCharges    (numeric: $0-10000)
  • Churn           (text: "Yes" or "No")

OPTIONAL (Recommended for better predictions):
  • Contract
  • InternetService
  • OnlineSecurity
  • TechSupport
  • StreamingTV

EXAMPLE CSV:
  CustomerID,Age,Tenure,MonthlyCharges,TotalCharges,Churn
  C001,32,12,65.50,786.00,No
  C002,45,8,95.25,762.00,Yes
