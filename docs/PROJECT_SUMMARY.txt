================================================================================
DATA REQUIREMENTS
================================================================================

Your CSV file needs these columns:
   • CustomerID      (string)
   • Age             (integer: 18-80)
   • Tenure          (integer: 0-80 months)
   • MonthlyCharges  (float: $0-150)
   • TotalCharges    (float: $0-10000)
   • Churn           (string: "Yes" or "No")

Optional columns for better predictions:
   • Contract, InternetService, OnlineSecurity, TechSupport, StreamingTV

TROUBLESHOOTING
================================================================================

"Module not found"
  → Run: pip install -r requirements.txt

App won't start
  → Check Python version (need 3.8+)
  → Check if port 8501 is available

CSV upload fails
  → Verify column names in your CSV
  → Check for encoding issues (use UTF-8)

No data showing
  → Upload CSV via Settings page first

ML predictions unavailable
  → Train model: python scripts/train_churn_model.py --data your.csv

Need help?
  → Check SETUP_INSTRUCTIONS.md
  → Review error messages (usually have solutions)
  → See QUICK_REFERENCE.md for commands
